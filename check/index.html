GitHub 上专做中转站验真的开源工具（153 星），盲测指纹比对，还能审计计费有没有注水。在电脑终端跑一行就行，不用装： npx relay-radar ping 你的中转站地址 验真命令和说明看它的仓库：https://github.com/AetherCore-Dev/relay-radar

注意：1）密钥只在你手机浏览器里直连对方接口，不经过任何第三方。2）如果报错连不上，多半是那家站没开跨域（CORS），不代表它有问题，换它家自带操练场手动问也行。3）每项测试都会真实调用接口，会消耗少量额度。
